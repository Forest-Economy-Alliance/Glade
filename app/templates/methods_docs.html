Phase 1 Methods And Techniques

Exact Duplicate Detection

Technique: perceptual hash (pHash-like) fingerprinting from compute_file_hash.

  • Images with identical hash are treated as exact duplicates.
  • Groups are written under exact_duplicates/phash_*.
  • CSV output: exact_duplicates.csv at output root.

Near Duplicate Detection

Method A: HSV Histogram + Cosine Similarity

  • Computes HSV histogram vector per image.
  • Uses cosine similarity matrix to cluster near duplicates.
  • Threshold controlled by near_duplicates.methods.hsv_cosine.similarity_threshold.

Method B: pHash Distance + Embedding Similarity

  • First gate: pHash Hamming distance.
  • Second gate: ResNet embedding cosine similarity.
  • Thresholds controlled by phash_max_distance and embed_similarity_threshold.

LLM Verification

  • Runs on near-duplicate groups CSV.
  • Provider and model are configurable in similarity_check_llm.
  • Confirmed groups are copied into exact_duplicates/llm_*.

Group Merging Logic

  • Builds a folder graph where two groups are connected if they share image names.
  • Connected components become final merged clusters in exact_duplicates_merged/merged_group_*.
  • Cluster summary CSV: merged_groups_summary.csv.

Original Image Selection Per Group

  • Selects one original image per merged group by earliest timestamp.
  • Timestamp priority: EXIF datetime -> metadata CSV datetime -> file modified time.
  • Originals copied to duplicates_original with unique names like groupid_filename.
  • Summary CSV: originals_extraction_summary.csv.

Final Unique Image Output

  • Final duplicates = exact duplicates + LLM-confirmed near duplicates.
  • Unique set = input images - final duplicates.
  • Copied into unique_images and listed in unique_images.csv.

Phase 2 will run label validation and quality checks on this Phase 1 unique output.
